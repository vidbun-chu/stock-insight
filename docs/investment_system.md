# 弱弱投资体系

## 核心理念

1. **市值最重要** — 一切围绕市值复利
2. **多和股票交朋友，少和股票谈恋爱** — 不和股票长相厮守
3. **简单粗暴的技术远胜于高大上的理论**

## 大周期定位（5月线系统）

| 市场状态 | 收盘/5月线比值 | 建议仓位 |
|----------|---------------|----------|
| 🟢 牛市 | > 1.02 | 80-100% |
| 🟡 结构性 | 1.00 ~ 1.02 | 60-80% |
| 🟠 猴市 | 0.98 ~ 1.00 | 40-60% |
| 🔴 熊市 | < 0.98 | 0-30% |

## 市值止损铁律

- 回撤3% → 半仓（仓位降至50%以下）
- 回撤5% → 清仓（仓位降至0%）
- 净资产未创新高之前 → 不加仓

## 仓位管理

- 小资金（10万以下）：单只≤30-40%，前3大≤70%
- 集中火力复利增长，不要过度分散

## 主线优先

- 跟随市场主线，不局限于任何行业
- 市场永远是对的，跟着市场走
- 判断标准：板块资金流向 + 涨幅排名 + 龙头表现 + 持续性

## 均线系统

- 5日线：超短线参考
- 10日线：短线趋势
- 20日线：中短线生命线
- 60日线：中线趋势
- 5月线：大周期生命线（牛熊分界）
